Satanic AI – Lizenz-System
==========================

AUFBAU
------
- license/worker.js  → Cloudflare Worker (Lizenz-Server)
- license/keys.json  → deine Key-Liste (einfach editierbar)
- KIStart.swift      → iOS: Lizenz-Check vor Pod-Start
- app.html           → Android/Windows: Lizenz-Check vor Pod-Start

DEPLOY (einmalig)
-----------------
1. Cloudflare-Konto anlegen (kostenlos): https://dash.cloudflare.com
2. Workers & Pages → Create Worker → Name: satanic-license
3. Code aus license/worker.js einfügen
4. Deploy klicken
5. Du bekommst eine URL wie: https://satanic-license.<dein-name>.workers.dev
6. Diese URL in KIStart.swift (Zeile: let url = URL(string: "...")!)
   und in app.html (Zeile: fetch("https://satanic-license...")) eintragen

KEYS ERZEUGEN
-------------
Jeder Käufer bekommt einen einzigartigen Key. Format: satanic-XXXX

1. Öffne license/keys.json
2. Füge einen neuen Eintrag hinzu:

   "satanic-a1b2": {
     "email": "käufer@mail.com",
     "fingerprint": "",
     "created_at": "2026-02-15T10:00:00Z",
     "revoked": false
   }

3. fingerprint: leer lassen → wird beim ersten Start automatisch gesetzt
   (der Worker speichert den Fingerprint des ersten Geräts)
4. keys.json auf Cloudflare hochladen (Workers → Settings → KV Storage
   oder einfach als Binding einbinden)

WICHTIG: Der Worker prüft:
- Key existiert?
- revoked = false?
- fingerprint passt? (leer = wird beim ersten Start gesetzt)

WIDERRUF (bei Weiterverkauf)
----------------------------
1. Öffne license/keys.json
2. Setze "revoked": true bei dem betroffenen Key
3. Hochladen → ab sofort sperrt sich die App beim nächsten Check

OFFLINE-TOLERANZ
----------------
- App akzeptiert letzte gültige Antwort für 7 Tage
- Danach: erneute Prüfung nötig
- Bei dauerhaftem Offline-Betrieb: App sperrt sich nach 7 Tagen

FINGERPRINT
-----------
- iOS: identifierForVendor + Model + Name + OS-Version → SHA-256
- Android/Windows: UserAgent + Sprache + Screen-Size + Timezone → Hash
- Wird beim ersten Start an den Worker gesendet und gespeichert
- Gerätetausch: neuer Fingerprint → neuer Key nötig (oder du setzt
  den Fingerprint im JSON auf den neuen Wert)

PROBLEME BEHEBEN
----------------
- "key_not_found" → Key falsch eingetragen oder nicht in keys.json
- "fingerprint_mismatch" → Gerät gewechselt → Fingerprint im JSON
  auf den neuen Wert setzen oder neuer Key
- "revoked" → Key wurde widerrufen → bei dir melden
- "Keine Verbindung" → Internet prüfen, Worker-URL korrekt?

KOSTEN
------
- Cloudflare Workers: kostenlos (100k Requests/Tag)
- KV Storage: kostenlos (1 GB)
- Reicht für tausende Käufer
