Satanic AI - Lizenz-System
==========================

WOZU
----
Jeder Kaeufer bekommt einen eigenen Key. Der Key wird beim ersten Start an
sein Geraet gebunden. Auf einem anderen Geraet oder nach einer Sperre startet
die App keinen Server mehr. Die Pruefung bremst Weitergabe, sie ist kein
unknackbarer Schutz.

AUFBAU
------
- license/worker.js     Lizenz-Server (Cloudflare Worker)
- license/wrangler.toml Einstellungen fuer die Uebertragung zu Cloudflare
- license/config.json   Adresse des Servers. Leer = Pruefung in den Apps aus.
- KIStart.swift, app.html  Pruefung vor dem Start, Eingabefeld fuer den Key
Keys, Geraetebindung und Sperren liegen im Cloudflare-Speicher (KV), nicht im Repo.

EINMAL EINRICHTEN
-----------------
1) Cloudflare: Mein Profil -> API-Token -> Token erstellen -> Vorlage
   "Edit Cloudflare Workers" -> erstellen und den Token kopieren.
2) GitHub: Repo -> Settings -> Secrets and variables -> Actions ->
   "New repository secret", zwei Stueck:
   CLOUDFLARE_API_TOKEN  = der Token aus Schritt 1
   LICENSE_ADMIN_PW      = dein Admin-Passwort (mindestens 12 Zeichen)
   Beides nie in einen Chat schreiben.
3) GitHub: Actions -> "Lizenz-Server" -> "Run workflow".
   Am Ende steht die Adresse des Servers in der Zusammenfassung.
4) Verwaltung oeffnen: <Adresse>/admin, mit dem Admin-Passwort anmelden,
   einen Key fuer dich selbst erzeugen.
5) Die Adresse in license/config.json bei "server" eintragen und pushen.
   Erst ab dem naechsten Build pruefen die Apps die Lizenz.

ALLTAG (in der Verwaltung)
--------------------------
- Key erzeugen: Notiz eingeben, "Key erzeugen", Key dem Kaeufer geben.
- Weitergabe oder Rueckbuchung: "Sperren".
- Kaeufer hat neues Geraet oder neu installiert: "Geraet zuruecksetzen".

FUER DEN KAEUFER
----------------
Key in den Einstellungen der App eintragen, "Lizenz pruefen" antippen, starten.
Ohne Internet gilt die letzte gueltige Pruefung noch 7 Tage.
